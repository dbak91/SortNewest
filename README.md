## SortNewest
An accessibility watcher that automatically selects a configured **Sort by...** option in the stock Android file picker. **Modified (newest first)** remains the default.

Confirmed picker options are file name A–Z/Z–A, type A–Z/Z–A, size smallest/largest first, and modified oldest/newest first.

## Notes 
- Only tested in English but attempts to use general android translations for automation. (the in app text remains English)
- Only tested on Pixel 7 emulated and Pixel 8a physical.
  
## Usage Instructions
- Enable Accessibility settings
- Choose an automatic sort order (or keep the newest-first default)
- Enable Monitoring
- Test picker

## Installation instructions [Accessibility options](video in release)
- Enable developer mode and unknown sources (Google for your model)
- Install apk by following the prompts (see tutorial)
- First press open accessibility settings, then attempt to turn on the setting for SortNewest and close the warning.
- Next on Android, go to Settings-Apps-SortNewest-Three dots-Allow restricted settings
- Go back to SortNewest or Accessibility settings and open.
- Turn on the first option for accessibility
- Return to SortNewest and enable monitoring
